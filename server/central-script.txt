// מיקום כל עמודה נקבע לפי הכותרת שלה בשורה 1 (כך שאפשר להזיז / להוסיף עמודות בגיליון בלי לשבור את המערכת)
const COL_KEYS = ['id', 'name', 'doc', 'active', 'ver', 'email', 'display', 'notes', 'key', 'settings', 'settingsLink', 'org', 'screens', 'nusach', 'display2', 'nesh', 'neshFile', 'neshDisplay', 'neshApp'];
let C = { id: 0, name: 1, doc: 2, active: 3, ver: 4, email: 5, display: 6, notes: 7, key: 8, settings: 9, settingsLink: 10, org: 11, screens: 12, nusach: 13, display2: 14, nesh: 15, neshFile: 16, neshDisplay: 17, neshApp: 18 };
function mapCols_(sh) {
  const last = Math.max(sh.getLastColumn(), 1);
  const h = sh.getRange(1, 1, 1, last).getValues()[0].map(x => String(x).replace(/\s+/g, ' ').trim());
  const m = {}; let next = last;
  COL_KEYS.forEach((k, i) => {
    let j = h.indexOf(HEAD[i]);
    if (j < 0 && k === 'name') j = h.findIndex(x => /^שם/.test(x));
    if (j < 0) { j = next++; sh.getRange(1, j + 1).setValue(HEAD[i]).setFontWeight('bold'); h[j] = HEAD[i]; }   // עמודה חסרה – נוספת בסוף
    m[k] = j;
  });
  C = m;
  return sh;
}
// בונה שורה חדשה לפי מיקומי העמודות
function rowOf_(vals) {
  const arr = new Array(Math.max.apply(null, COL_KEYS.map(k => C[k])) + 1).fill('');
  Object.keys(vals).forEach(k => { arr[C[k]] = vals[k]; });
  return arr;
}

// ---------- עדכון עצמי של הקוד מ-GitHub ----------
// מושך את server/central-script.txt מהמאגר, מחליף את קובץ הקוד בפרויקט, יוצר גרסה ומעדכן את הפריסה הקיימת (אותה כתובת /exec).
// דורש פעם אחת: Google Apps Script API דולק (script.google.com/home/usersettings), והרשאות script.projects ו-script.deployments ב-appsscript.json
const CODE_URL = 'https://raw.githubusercontent.com/oferme/zmanim/main/server/central-script.txt';
function selfUpdate_() {
  const code = UrlFetchApp.fetch(CODE_URL + '?t=' + Date.now(), { muteHttpExceptions: true });
  if (code.getResponseCode() !== 200) throw new Error('לא הצלחתי להוריד את הקוד מ-GitHub (' + code.getResponseCode() + ')');
  const src = code.getContentText();
  const nb = +((src.match(/const SERVER_BUILD = (\d+)/) || [])[1] || 0);
  if (!nb || src.length < 20000 || src.indexOf('function doGet') < 0 || src.indexOf('function selfUpdate_') < 0) throw new Error('הקובץ שהורד לא נראה כמו קוד השרת – לא עודכן');
  const id = ScriptApp.getScriptId(), api = 'https://script.googleapis.com/v1/projects/' + id;
  const call = (method, path, body) => {
    const r = UrlFetchApp.fetch(api + path, { method, contentType: 'application/json', muteHttpExceptions: true,
      headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() }, payload: body ? JSON.stringify(body) : undefined });
    const t = r.getContentText();
    if (r.getResponseCode() >= 300) {
      if (/has not been used|is disabled|SERVICE_DISABLED|User has not enabled/i.test(t)) throw new Error('צריך להדליק את Google Apps Script API: script.google.com/home/usersettings');
      if (/insufficient authentication scopes/i.test(t)) throw new Error('חסרות הרשאות script.projects / script.deployments בקובץ appsscript.json\n' + t.slice(0, 300));
      throw new Error('Apps Script API ' + r.getResponseCode() + ': ' + t.slice(0, 300));
    }
    return t ? JSON.parse(t) : {};
  };
  const content = call('get', '/content');
  const files = content.files || [];
  const f = files.find(x => x.type === 'SERVER_JS' && /const SERVER_BUILD =/.test(x.source || '')) || files.find(x => x.type === 'SERVER_JS');
  if (!f) throw new Error('לא נמצא קובץ קוד בפרויקט');
  if (f.source === src) return { same: true, build: nb };
  f.source = src;
  call('put', '/content', { files: files.map(x => ({ name: x.name, type: x.type, source: x.source })) });
  const ver = call('post', '/versions', { description: 'עדכון מ-GitHub – גרסת שרת ' + nb });
  const depId = (API_URL.match(/\/s\/([\w-]+)\/exec/) || [])[1];
  if (!depId) throw new Error('הקוד עודכן, אבל לא נמצאה כתובת הפריסה (API_URL) – יש לפרוס גרסה חדשה ידנית');
  call('put', '/deployments/' + depId, { deploymentConfig: { scriptId: id, versionNumber: ver.versionNumber, manifestFileName: 'appsscript', description: 'גרסת שרת ' + nb } });
  return { build: nb, version: ver.versionNumber };
}
function updateFromGithub() {
  const ui = SpreadsheetApp.getUi();
  try {
    const r = selfUpdate_();
    ui.alert(r.same ? 'הקוד כבר מעודכן (גרסת שרת ' + r.build + ').' : 'הקוד עודכן ונפרס! גרסת שרת ' + r.build + ' (גרסה ' + r.version + ' בפריסה).\nהמסכים יתעדכנו תוך כמה דקות.');
  } catch (e) { ui.alert('העדכון לא הצליח:\n' + (e && e.message || e)); }
}

// ---------- גיבוי ----------
// עותק של הגיליון (כולל הקוד שמחובר אליו) לתיקייה "גיבויים – לוח זמנים" בדרייב. נשמרים 30 העותקים האחרונים.
// בכל יום ראשון נשלח גם קובץ Excel של הגיליון למייל של בעל הסקריפט – עותק מחוץ לדרייב.
const BACKUP_FOLDER = 'גיבויים – לוח זמנים';
function backupFolder_() {
  const it = DriveApp.getFoldersByName(BACKUP_FOLDER);
  return it.hasNext() ? it.next() : DriveApp.createFolder(BACKUP_FOLDER);
}
function makeBackup_(sendMail) {
  const ss = sheet_().getParent(), folder = backupFolder_();
  const stamp = Utilities.formatDate(new Date(), 'Asia/Jerusalem', 'yyyy-MM-dd HH-mm');
  DriveApp.getFileById(ss.getId()).makeCopy('גיבוי ' + stamp + ' – ' + ss.getName(), folder);
  const files = [], it = folder.getFiles();
  while (it.hasNext()) files.push(it.next());
  files.sort((a, b) => b.getDateCreated() - a.getDateCreated());
  files.slice(30).forEach(f => { try { f.setTrashed(true); } catch (e) {} });
  if (sendMail) {
    const url = 'https://docs.google.com/spreadsheets/d/' + ss.getId() + '/export?format=xlsx';
    const blob = UrlFetchApp.fetch(url, { headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() } }).getBlob()
      .setName('גיבוי לוח זמנים ' + stamp + '.xlsx');
    MailApp.sendEmail(Session.getEffectiveUser().getEmail(), 'גיבוי שבועי – ניהול בתי כנסת', 'מצורף גיבוי של גיליון הניהול (' + stamp + ').\nכדאי לשמור את המייל.', { attachments: [blob] });
  }
  return stamp;
}
function backupNow() {
  const stamp = makeBackup_(true);
  SpreadsheetApp.getUi().alert('הגיבוי נשמר (' + stamp + ') בתיקייה "' + BACKUP_FOLDER + '" בדרייב, ונשלח עותק Excel למייל שלך.');
}
function backupNightly() { makeBackup_(new Date().getDay() === 0); }   // כל לילה; ביום ראשון – גם למייל
function enableBackup() {
  ScriptApp.getProjectTriggers().filter(t => t.getHandlerFunction() === 'backupNightly').forEach(t => ScriptApp.deleteTrigger(t));
  ScriptApp.newTrigger('backupNightly').timeBased().everyDays(1).atHour(2).inTimezone('Asia/Jerusalem').create();
  SpreadsheetApp.getUi().alert('הגיבוי האוטומטי הופעל: כל לילה בסביבות 2:00 נשמר עותק בדרייב, ובכל יום ראשון נשלח גם קובץ Excel למייל שלך.');
}

  const sh = sheet_(), rows = sh.getDataRange().getValues();
  for (let i = 1; i < rows.length; i++) if (String(rows[i][C.id]).trim().toLowerCase() === id) return { sh, r: i + 1, row: rows[i] };

}

// ---------- הוספת בית כנסת ----------
function addShul() {
  const ui = SpreadsheetApp.getUi();
  const ask = (q) => { const r = ui.prompt(q, ui.ButtonSet.OK_CANCEL); return r.getSelectedButton() === ui.Button.OK ? r.getResponseText().trim() : null; };

  const id = (ask('מזהה קצר באנגלית (אותיות, ספרות ומקף), למשל: ohel-moshe') || '').toLowerCase();
  if (!id) return;
  if (!/^[a-z0-9-]+$/.test(id)) { ui.alert('המזהה יכול להכיל רק אותיות באנגלית, ספרות ומקף.'); return; }
  if (findRow_(id)) { ui.alert('המזהה הזה כבר קיים.'); return; }
  const name = ask('שם בית הכנסת');
  if (name === null) return;
  const org = ask('שם בית הכנסת / המוסד (לקיבוץ כמה היכלות יחד). אם זה היכל יחיד – אפשר להשאיר ריק');
  if (org === null) return;
  const scr = ask('כמה מסכים מאושרים להיכל הזה? (מספר)');
  if (scr === null) return;
  const email = ask('מייל (ג׳ימייל) של הגבאי/הרב – אפשר להשאיר ריק');
  if (email === null) return;
  const nusach = ask('נוסח בית הכנסת: אשכנז / ספרד / עדות המזרח – אפשר להשאיר ריק');
  if (nusach === null) return;

  const docUrl = createDoc_(name, email);
  const doc = { getUrl: () => docUrl };

  const key = newKey_(), display = DISPLAY_URL + '?shul=' + id, sLink = settingsLink_(id, key);
  const sh = sheet_();
  const nScr = Math.max(1, parseInt(scr, 10) || 1);
  sh.appendRow(rowOf_({ id, name, doc: doc.getUrl(), active: 'כן', ver: 1, email, display, key, settings: JSON.stringify(defaults_(name)),
    settingsLink: sLink, org: org || name, screens: nScr, nusach, display2: nScr >= 2 ? display + '&screen=2' : '' }));

  if (email) {
    try {
      MailApp.sendEmail(email, 'לוח הזמנים של ' + name,
        'שלום,\n\nלעריכת ההגדרות של המסך (מהטלפון או מהמחשב):\n' + sLink +
        '\n\nלכתיבת הודעות למסך:\n' + doc.getUrl() + '\n\nכדאי לשמור את שני הקישורים במסך הבית של הטלפון.');
    } catch (e) {}
  }
  ui.alert('בית הכנסת נוסף!\n\nקישור למסך:\n' + display + '\n\nקישור להגדרות (לגבאי):\n' + sLink + '\n\nמסמך ההודעות:\n' + doc.getUrl());
}

// יוצר מפתח לשורות בלי מפתח, ומעדכן את כל קישורי ההגדרות לכתובת העדכנית (המפתחות הקיימים נשמרים)
function fillMissingLinks() {
  const ui = SpreadsheetApp.getUi();
  const sh = sheet_(), rows = sh.getDataRange().getValues();
  let n = 0, d = 0;
  let fixed = 0, mig = 0, rest = 0;
  const amb = [];   // לא שוחזר – נמצא יותר מקובץ אחד מתאים
  let nIdx = null;  // אינדקס קבצי לוח הנשמה (נבנה רק כשצריך)
  for (let i = 1; i < rows.length; i++) {
    // שורה שנוספה בגרסה קודמת לפי סדר עמודות קבוע (המפתח בעמודה I) – מועברת לעמודות הנכונות לפי הכותרות
    const old = rows[i];
    if (C.key !== 8 && !/^[0-9a-f]{14}$/.test(String(old[C.key] || '').trim()) && /^[0-9a-f]{14}$/.test(String(old[8] || '').trim())) {
      const vals = {}; COL_KEYS.forEach((k, j) => { vals[k] = old[j] === undefined ? '' : old[j]; });
      const arr = rowOf_(vals), width = Math.max(arr.length, old.length);
      while (arr.length < width) arr.push('');
      sh.getRange(i + 1, 1, 1, width).setValues([arr]);
      rows[i] = arr; fixed++;
    }
    const id = String(rows[i][C.id]).trim().toLowerCase();
    if (!id) continue;
    let key = String(rows[i][C.key] || '');
    if (!key) { key = newKey_(); sh.getRange(i + 1, C.key + 1).setValue(key); n++; }
    sh.getRange(i + 1, C.settingsLink + 1).setValue(settingsLink_(id, key));
    sh.getRange(i + 1, C.display + 1).setValue(DISPLAY_URL + '?shul=' + id);
    // קישור למסך 2 – רק כשמספר המסכים 2 ומעלה
    sh.getRange(i + 1, C.display2 + 1).setValue((parseInt(rows[i][C.screens], 10) || 1) >= 2 ? DISPLAY_URL + '?shul=' + id + '&screen=2' : '');
    if (!neshFileId_(rows[i])) {   // הקישור לקובץ לוח הנשמה נמחק? – מחפשים את הקובץ בתיקייה
      nIdx = nIdx || neshIndex_();
      const r = neshFind_(nIdx, id, String(rows[i][C.name] || id));
      if (r.url) { sh.getRange(i + 1, C.neshFile + 1).setValue(r.url); rows[i][C.neshFile] = r.url; rest++; }
      else if (r.many) amb.push('לוח נשמה של ' + String(rows[i][C.name] || id));
    }
    if (neshFileId_(rows[i])) {   // לוח נשמה: קישורי המסך והאפליקציה
      const nl = neshLinks_(id, key);
      sh.getRange(i + 1, C.neshDisplay + 1).setValue(nl.display);
      sh.getRange(i + 1, C.neshApp + 1).setValue(nl.app);
    }
    const st = parseJson_(rows[i][C.settings]);
    if (st && migrateDaf_(st)) { sh.getRange(i + 1, C.settings + 1).setValue(JSON.stringify(st)); mig++; }

function createDoc_(name, email) {
  const doc = DocumentApp.create('הודעות – ' + name);
  const body = doc.getBody();
  TEMPLATE().split('\n').forEach((line, i) => {
    let p;
    if (i === 0) { p = body.getParagraphs()[0]; p.setText(line); }
    else p = body.appendParagraph(line);
    p.setLeftToRight(false);
    p.setAlignment(DocumentApp.HorizontalAlignment.RIGHT);
  });
  doc.saveAndClose();
  if (email) { try { DriveApp.getFileById(doc.getId()).addEditor(email); } catch (e) {} }
  return doc.getUrl();
}

  if (what === 'img') {   // תמונה למרכז מסך התמונה – רק תמונה ששייכת להגדרות של בית הכנסת הזה
    const f = findRow_(id); const st = f ? parseJson_(f.row[C.settings]) || {} : {};

    if (!fid || !picImages_(st).includes(fid)) return out('');
    try {
      const b = DriveApp.getFileById(fid).getBlob();
      return out('data:' + b.getContentType() + ';base64,' + Utilities.base64Encode(b.getBytes()));
    } catch (e) { return out(''); }
  }
  if (what === 'logo') {   // הלוגו כ-data URL דרך השרת – כך הוא עובר גם במחשבים עם סינון שחוסם את googleusercontent
    const f = findRow_(id); const st = f ? parseJson_(f.row[C.settings]) || {} : {};

    try {
      const b = DriveApp.getFileById(st.logoId).getBlob();
      const d = 'data:' + b.getContentType() + ';base64,' + Utilities.base64Encode(b.getBytes());
      if (d.length < 95000) cache.put('logo_' + st.logoId, d, 21600);
      return out(d);
    } catch (e) { return out(''); }
  }
  if (what !== 'version' && what !== 'zoom') {   // אישור מסך (לא נדרש לבדיקת גרסה ולתוכנת הזום במחשב)
    const dev = String(p.dev || '').replace(/[^a-z0-9]/gi, '').slice(0, 32);
    const err = checkDevice_(id, dev, String(p.code || '').replace(/\D/g, '').slice(0, 6), cache);
    if (err) return out(err);
  }
  const ck = what + 'shul_' + id + (scr === 2 ? '_2' : '');

  if (!f) return out('ERR:NOT_FOUND');

  const active = String(row[C.active]).trim();

  if (active === 'לא' || active.toLowerCase() === 'false') {
    text = 'ERR:INACTIVE';
  } else {
    text = '';
    const m = String(row[C.doc]).match(/[-\w]{25,}/);

      const file = DriveApp.getFileById(m[0]);
      text = file.getMimeType() === MimeType.GOOGLE_DOCS
        ? DocumentApp.openById(m[0]).getBody().getText()
        : file.getBlob().getDataAsString('UTF-8');
    }
    const s = parseJson_(row[C.settings]);
    if (s) nusachDefault_(s, row);
    if (s) {   // הגדרות מהטופס גוברות על שורות ! במסמך (חוץ מטבלת נץ)

    }
    text += '\n! גרסת מערכת: ' + ver + '\n! גרסת שרת: ' + SERVER_BUILD;
  }
  cache.put(ck, text, 60);
  return out(text);
}
// בודק אם המסך מאושר. מסכים חדשים מאושרים אוטומטית עד המכסה ("מספר מסכים"), מעבר לזה – ממתינים לאישור ידני
// kind 'n' = מסך לוח נשמה: נרשם בלשונית "מסכים" כ"<מזהה> לוח נשמה", והמכסה מעמודה "לוח נשמה"
function checkDevice_(id, dev, code, cache, kind) {
  if (!dev) return 'ERR:DEVICE:0000';
  const nesh = kind === 'n', label = nesh ? id + ' לוח נשמה' : id;
  const ck = (nesh ? 'devn_' : 'dev_') + id + '_' + dev;
  if (cache.get(ck) === '1') return null;
  const lock = LockService.getScriptLock(); lock.waitLock(10000);
  try {
    const f = findRow_(id);
    if (!f) return 'ERR:NOT_FOUND';
    const dv = devSheet_(), rows = dv.getDataRange().getValues(), now = new Date();
    let approved = 0;
    for (let i = 1; i < rows.length; i++) {
      if (String(rows[i][D.shul]).trim().toLowerCase() !== label) continue;
      if (String(rows[i][D.dev]) === dev) {
        dv.getRange(i + 1, D.last + 1).setValue(now);
        const st = String(rows[i][D.status]).trim();
        if (st === 'מאושר') { cache.put(ck, '1', 600); return null; }
        return 'ERR:DEVICE:' + rows[i][D.code];
      }
      if (String(rows[i][D.status]).trim() === 'מאושר') approved++;
    }
    const quota = nesh ? (parseInt(f.row[C.nesh], 10) || 0) : Math.max(1, parseInt(f.row[C.screens], 10) || 1);
    const ok = approved < quota;
    dv.appendRow([dev, code || '----', label, ok ? 'מאושר' : 'ממתין', now, now, '']);
    if (ok) { cache.put(ck, '1', 600); return null; }
    return 'ERR:DEVICE:' + (code || '----');
  } finally { lock.releaseLock(); }
}

function doPost(e) {
  try {

    const id = String(b.shul || '').toLowerCase();

    if (b.action === 'logo') return json_(saveLogo_(id, b.key, String(b.data || '')));
    if (b.action === 'img') return json_(saveImage_(id, b.key, String(b.data || '')));
    if (b.action === 'aiTable') return json_(aiTable_(id, b.key, String(b.data || '')));
    if (/^n(put|del|set)$/.test(String(b.action))) return json_(neshPost_(id, b.key, b));   // אפליקציית לוח הנשמה
    saveSettings(id, b.key, b.s || {});
    return json_({ ok: true });
  } catch (err) { return json_({ ok: false, error: String(err && err.message || err) }); }
}

// יוטיוב – "השיעור האחרון": מקבל קישור לערוץ (youtube.com/@name או /channel/UC...) או לרשימת השמעה (list=...),
// וקורא את רשימת הסרטונים (RSS) של יוטיוב. מחזיר קישור לסרטון האחרון שעלה (אפשר לסנן לפי מילה בכותרת). נשמר במטמון 10 דקות
function ytLatest_(link, filter, debug) {
  const cache = CacheService.getScriptCache(), ck = 'yt_' + Utilities.base64EncodeWebSafe(link + '|' + (filter || '')).slice(0, 200);
  if (!debug) { const hit = cache.get(ck); if (hit !== null) return hit; }
  const info = { link, filter: filter || '', channel: '', feed: '', titles: [], chosen: '', error: '' };
  let m;
  if (!/^https:\/\/(www\.|m\.)?youtube\.com\//i.test(link)) info.error = 'הקישור צריך להיות לערוץ או לרשימת השמעה ב-youtube.com';
  else if ((m = link.match(/[?&]list=([\w-]+)/))) info.feed = 'playlist_id=' + m[1];
  else if ((m = link.match(/\/channel\/(UC[\w-]{22})/))) info.feed = 'channel_id=' + m[1];
  else if (/youtube\.com\/(@|c\/|user\/)/.test(link)) {   // כתובת עם שם ערוץ – מוצאים את מזהה הערוץ מהדף
    const page = link.split('?')[0];
    const ck2 = 'ytch_' + Utilities.base64EncodeWebSafe(page).slice(0, 200);
    let ch = debug ? null : cache.get(ck2);
    if (!ch) {
      try {
        const html = UrlFetchApp.fetch(page, { muteHttpExceptions: true, headers: { 'Accept-Language': 'en' } }).getContentText();
        ch = ((html.match(/"(?:channelId|externalId|browseId)":"(UC[\w-]{22})"/) || html.match(/channel\/(UC[\w-]{22})/)) || [])[1] || '';
        if (!ch) info.error = 'לא נמצא מזהה ערוץ בדף';
      } catch (e) { ch = ''; info.error = String(e); }
      if (ch) cache.put(ck2, ch, 21600);
    }
    info.channel = ch || '';
    if (ch) info.feed = 'channel_id=' + ch;
  } else info.error = 'הקישור אינו לערוץ או לרשימת השמעה';
  if (info.feed) {
    const unesc = t => String(t || '').replace(/&amp;/g, '&').replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&lt;/g, '<').replace(/&gt;/g, '>');
    let all = [];
    info.tried = [];
    // 1. רשימת הסרטונים (RSS) של הערוץ / רשימת ההשמעה
    // 2. אם ריקה – רשימת ההעלאות של הערוץ (UU...)
    // 3. אם עדיין ריקה – דף הסרטונים והשידורים של הערוץ ביוטיוב
    const feeds = [info.feed];
    const chId = (info.feed.match(/channel_id=(UC[\w-]{22})/) || [])[1];
    if (chId) feeds.push('playlist_id=UU' + chId.slice(2));
    for (const fd of feeds) {
      if (all.length) break;
      try {
        const r = UrlFetchApp.fetch('https://www.youtube.com/feeds/videos.xml?' + fd, { muteHttpExceptions: true });
        info.tried.push(fd + ' → ' + r.getResponseCode());
        if (r.getResponseCode() !== 200) continue;
        const xml = r.getContentText();
        const tag = (e, t) => unesc((e.match(new RegExp('<' + t + '[^>]*>([\\s\\S]*?)</' + t + '>')) || [])[1]);
        all = (xml.match(/<entry>[\s\S]*?<\/entry>/g) || []).map(e => ({ id: tag(e, 'yt:videoId'), title: tag(e, 'title'), at: tag(e, 'published') }));
        all.sort((x, y) => y.at.localeCompare(x.at));
      } catch (e) { info.tried.push(fd + ' → ' + e); }
    }
    if (!all.length && chId) {
      for (const tab of ['videos', 'streams']) {
        try {
          const r = UrlFetchApp.fetch('https://www.youtube.com/channel/' + chId + '/' + tab, { muteHttpExceptions: true, headers: { 'Accept-Language': 'he,en' } });
          info.tried.push(tab + ' page → ' + r.getResponseCode());
          if (r.getResponseCode() !== 200) continue;
          const html = r.getContentText(), seen = {};
          // סרטונים בדף: videoRenderer (videoId + title.runs) או lockupViewModel (contentId + title.content)
          const re = /"videoRenderer":\{"videoId":"([\w-]{11})"[\s\S]{0,3000}?"title":\{"runs":\[\{"text":"((?:[^"\\]|\\.)*)"|"lockupViewModel":\{[\s\S]{0,6000}?"title":\{"content":"((?:[^"\\]|\\.)*)"[\s\S]{0,3000}?"contentId":"([\w-]{11})"/g;
          let m, i = 0;
          while ((m = re.exec(html)) && i < 40) {
            const id = m[1] || m[4], title = m[2] !== undefined ? m[2] : m[3];
            if (!id || seen[id]) continue; seen[id] = 1;
            let t = title; try { t = JSON.parse('"' + title + '"'); } catch (e) {}
            all.push({ id, title: t, at: tab + ' #' + String(++i).padStart(2, '0') });
          }
        } catch (e) { info.tried.push(tab + ' page → ' + e); }
        if (all.length) break;   // דף הסרטונים מסודר מהחדש לישן
      }
    }
    try {
      info.titles = all.map(x => x.at.slice(0, 16) + ' ' + x.title);
      const norm = t => String(t).replace(/[֑-ׇ"'״׳`.,:;!?()\[\]\-–|]/g, ' ').replace(/\s+/g, ' ').trim().toLowerCase();
      const words = norm(filter || '').split(' ').filter(Boolean);   // כל המילים צריכות להופיע בשם (בכל סדר)
      const pick = all.find(x => x.id && words.every(w => norm(x.title).indexOf(w) >= 0));
      if (pick) info.chosen = 'https://www.youtube.com/watch?v=' + pick.id;
      else if (!all.length) info.error = 'רשימת הסרטונים ריקה או לא נטענה';
      else info.error = 'אף סרטון לא מתאים לסינון';
    } catch (e) { info.error = String(e); }
  }
  // הסרטון האחרון שנמצא נשמר. אם הפעם יוטיוב לא החזיר את הרשימה, או שבין 15 הסרטונים האחרונים אין אחד שמתאים לסינון –
  // מציגים את האחרון שנמצא, במקום הודעה "לא נמצא סרטון"
  const pk = 'ytlast_' + Utilities.base64EncodeWebSafe(Utilities.computeDigest(Utilities.DigestAlgorithm.MD5, link + '|' + (filter || ''))).slice(0, 22);
  const props = PropertiesService.getScriptProperties();
  if (info.chosen) { try { props.setProperty(pk, info.chosen); } catch (e) {} }
  else { const last = props.getProperty(pk); if (last) { info.chosen = last; info.fallback = 'הוצג הסרטון האחרון שנמצא קודם (' + info.error + ')'; } }
  if (debug) return info;
  cache.put(ck, info.chosen, info.chosen ? 600 : 120);
  return info.chosen;
}
// קישור זום מקוצר / מפנה (למשל https://zoom.mdydaf.com) – עוקבים אחרי ההפניות עד לקישור האמיתי zoom.us/j/...
function resolveZoom_(link) {
  if (/zoom\.(us|com)\/(j|w|wc\/join)\/\d+/i.test(link)) return link;
  const cache = CacheService.getScriptCache(), ck = 'zr_' + Utilities.base64EncodeWebSafe(link).slice(0, 200);
  const hit = cache.get(ck); if (hit !== null) return hit || link;
  let url = link, out = '';
  try {
    for (let i = 0; i < 6 && !out; i++) {
      const r = UrlFetchApp.fetch(url, { followRedirects: false, muteHttpExceptions: true });
      const h = r.getAllHeaders(), loc = h.Location || h.location;
      const found = s => (String(s || '').match(/https:\/\/[\w.-]*zoom\.(?:us|com)\/(?:j|w)\/\d+[^\s"'<>]*/i) || [])[0];
      if (loc) { if (found(loc)) out = found(loc); else url = /^https?:/i.test(loc) ? loc : url.replace(/^(https?:\/\/[^/]+).*$/, '$1') + loc; }
      else { out = found(r.getContentText()) || ''; break; }
    }
  } catch (e) {}
  out = out.replace(/&amp;/g, '&');
  cache.put(ck, out, out ? 21600 : 300);
  return out || link;
}

const PT_DAYS = ['fri', 'sat', 'motz'];
function cleanPtable_(t) {
  t = t && typeof t === 'object' ? t : {};

  const rows = (Array.isArray(t.rows) ? t.rows : []).slice(0, 80).map(r => ({

  return { on: t.on !== false, cols, rows, at: /^\d{4}-\d{2}-\d{2}$/.test(t.at) ? t.at : '' };
}

function aiCall_(provider, b64, mime) {
  const p = aiProps_();
  if (provider === 'claude') {
    const key = p.getProperty('CLAUDE_KEY'); if (!key) return null;
    const part = mime === 'application/pdf' ? { type: 'document', source: { type: 'base64', media_type: mime, data: b64 } } : { type: 'image', source: { type: 'base64', media_type: mime, data: b64 } };
    return { provider, url: 'https://api.anthropic.com/v1/messages', method: 'post', contentType: 'application/json', muteHttpExceptions: true,
      headers: { 'x-api-key': key, 'anthropic-version': '2023-06-01' },
      payload: JSON.stringify({ model: p.getProperty('CLAUDE_MODEL') || 'claude-sonnet-5-5', max_tokens: 8000,
        messages: [{ role: 'user', content: [part, { type: 'text', text: AI_PROMPT }] }] }) };
  }
  const key = p.getProperty('GEMINI_KEY'); if (!key) return null;
  return { provider: 'gemini', url: 'https://generativelanguage.googleapis.com/v1beta/models/' + (p.getProperty('GEMINI_MODEL') || 'gemini-flash-latest') + ':generateContent',
    method: 'post', contentType: 'application/json', muteHttpExceptions: true, headers: { 'x-goog-api-key': key },
    payload: JSON.stringify({ contents: [{ role: 'user', parts: [{ inline_data: { mime_type: mime, data: b64 } }, { text: AI_PROMPT }] }],
      generationConfig: { temperature: 0, responseMimeType: 'application/json' } }) };
}
function aiParse_(provider, res) {
  const code = res.getResponseCode(), body = parseJson_(res.getContentText()) || {};
  if (code !== 200) return { error: (provider === 'claude' ? 'Claude' : 'Gemini') + ': ' + ((body.error && (body.error.message || body.error.type)) || ('שגיאה ' + code)) };
  const txt = provider === 'claude' ? (body.content || []).filter(x => x.type === 'text').map(x => x.text).join('')
    : ((((body.candidates || [])[0] || {}).content || {}).parts || []).map(x => x.text || '').join('');
  const m = String(txt).match(/\{[\s\S]*\}/);
  const j = m ? parseJson_(m[0]) : null;
  if (!j) return { error: 'התשובה מהבינה המלאכותית לא הייתה תקינה – נסו שוב' };
  if (j.error) return { error: String(j.error).slice(0, 200) };
  // ניקוי: רק מה שהאפליקציה מבינה
  const cols = (Array.isArray(j.cols) ? j.cols : []).slice(0, 16).map(c => ({ label: String(c.label || '').trim().slice(0, 30), day: PT_DAYS.includes(c.day) ? c.day : 'sat', sure: c.sure !== false }));
  const rows = (Array.isArray(j.rows) ? j.rows : []).slice(0, 80).map(r => Array.isArray(r) ? r : [r && r.k].concat(r && r.v || []))
    .map(r => ({ k: String(r[0] || '').trim().slice(0, 40), v: cols.map((c, i) => String(r[i + 1] == null ? '' : r[i + 1]).trim().slice(0, 20)) })).filter(r => r.k);
  const unsure = (Array.isArray(j.unsure) ? j.unsure : []).filter(x => Array.isArray(x) && x.length === 2).map(x => [+x[0], +x[1]]).filter(x => x[0] >= 0 && x[0] < rows.length && x[1] >= 0 && x[1] < cols.length).slice(0, 200);
  const weekday = (Array.isArray(j.weekday) ? j.weekday : []).slice(0, 20).map(w => ({ label: String(w.label || '').trim().slice(0, 30), value: String(w.value || '').trim().slice(0, 120),
    q: ['', 'חול', 'א-ה', 'שישי', 'שבת'].includes(w.q) ? w.q : '', sure: w.sure !== false })).filter(w => w.label);
  const questions = (Array.isArray(j.questions) ? j.questions : []).slice(0, 6).map(q => ({ text: String(q.text || '').slice(0, 200),
    target: q.target && Number.isInteger(+q.target.w) && q.target.w !== undefined ? { w: +q.target.w } : q.target && q.target.col !== undefined ? { col: +q.target.col } : {},
    options: (Array.isArray(q.options) ? q.options : []).slice(0, 5).map(o => ({ label: String(o.label || o.value || '').slice(0, 40), value: String(o.value == null ? '' : o.value).slice(0, 120) })) }))
    .filter(q => q.text && q.options.length);
  return { provider, title: String(j.title || '').slice(0, 80), cols, rows, unsure, weekday, questions, notes: (Array.isArray(j.notes) ? j.notes : []).map(String).slice(0, 8) };
}
function aiTable_(id, key, data) {
  const f = id ? findRow_(id) : null;
  if (!f || !key || String(f.row[C.key]) !== key) return { ok: false, error: 'אין הרשאה' };

  const m = data.match(/^data:(image\/(?:jpeg|png|webp)|application\/pdf);base64,(.+)$/);
  if (!m) return { ok: false, error: 'אפשר להעלות תמונה (JPG / PNG) או PDF' };
  if (m[2].length > 14e6) return { ok: false, error: 'הקובץ גדול מדי' };
  const p = aiProps_(), cache = CacheService.getScriptCache(), qk = 'aiq_' + id + '_' + Utilities.formatDate(new Date(), 'Asia/Jerusalem', 'yyyyMMdd');
  const used = +(cache.get(qk) || 0), lim = +(p.getProperty('AI_DAILY') || 15);
  if (used >= lim) return { ok: false, error: 'הגעתם למכסה היומית של קריאה מתמונות (' + lim + '). נסו מחר.' };
  cache.put(qk, String(used + 1), 6 * 3600);
  const first = p.getProperty('AI_PROVIDER') === 'claude' || !p.getProperty('GEMINI_KEY') ? 'claude' : 'gemini';
  const list = (p.getProperty('AI_COMPARE') === '1' ? [first, first === 'claude' ? 'gemini' : 'claude'] : [first]).map(x => aiCall_(x, m[2], m[1])).filter(Boolean);
  if (!list.length) return { ok: false, error: 'אין מפתח לספק שנבחר' };
  const res = UrlFetchApp.fetchAll(list.map(r => { const o = Object.assign({}, r); delete o.provider; return o; }));
  const out = res.map((r, i) => aiParse_(list[i].provider, r));
  const good = out.filter(x => !x.error);
  if (!good.length) return { ok: false, error: out[0].error };
  return { ok: true, r: good[0], alt: good[1] || null };
}

function halBook_(id, h, day, sig) {
  const start = h.date || day;
  const n = daysBetween_(start, day);
  if (n < 0) return { ok: false, error: 'הלימוד מתחיל ב-' + start };
  // נקודת ההתחלה
  let ref = h.book;
  if (h.start === 'siman') ref = h.book + '.' + h.siman + '.' + h.seif;
  if (h.start === 'link' && h.link) ref = decodeURIComponent(h.link.replace(/^https:\/\/[^/]+\//, '').split(/[?#]/)[0]).replace(/_/g, ' ');
  const props = PropertiesService.getScriptProperties(), pk = 'hal_' + id;

  if (!st || st.sig !== sig || st.day > day) {   // הגדרה חדשה – מתחילים מנקודת ההתחלה
    const first = halSection_(ref, '');
    ver = halVersion_(first.index || h.book);
    if (!ver.vt) throw new Error('לא נמצאה בספריא מהדורה עברית של הספר עם רישיון לשימוש מסחרי' + (ver.none ? ': ' + ver.none : ''));
    const sec = halSection_(first.ref, ver.vt);
    const isSeg = first.depth && first.sections.length >= first.depth;   // הקישור / ההתחלה מצביעים על סעיף מסוים
    st = { sig, vt: ver.vt, lic: ver.lic, index: first.index || h.book, first: sec.ref, ref: sec.ref, idx: isSeg ? Math.max(0, first.sections[first.sections.length - 1] - 1) : 0, day: start };
  }
  // התקדמות עד היום
  let left = h.per * daysBetween_(st.day, day), guard = 0;
  while (left > 0 && guard++ < 3000) {
    const sec = halSection_(st.ref, st.vt), remain = sec.segs.length - st.idx;
    if (left < remain) { st.idx += left; left = 0; break; }
    left -= Math.max(0, remain); st.ref = sec.next || st.first; st.idx = 0;
  }
  st.day = day;
  props.setProperty(pk, JSON.stringify(st));
  // ההלכות של היום
  const items = []; let r = st.ref, i = st.idx; guard = 0;

// לכל בית כנסת קובץ גיליון משלו בתיקייה "לוחות נשמה" (כדי שגיליון הניהול יישאר קטן גם עם אלפי בתי כנסת).
// בגיליון הניהול: עמודה "לוח נשמה" = כמה מסכי לוח נשמה מאושרים (ריק / 0 = כבוי), "קובץ לוח נשמה" = קישור לקובץ.
// בקובץ: לשונית "נפטרים" (שורה לכל נפטר) ולשונית "הגדרות" (מפתח | ערך | הסבר).
// התאריכים נשמרים כטקסט עברי (י״ח | חשון | תשנ״ב), והחישוב (יארצייט, השבוע) נעשה במסך – neshama/heb.js
const NESH_FOLDER = 'לוחות נשמה';
const NESH_TAB = 'נפטרים', NESH_SET_TAB = 'הגדרות';
const NESH_HEAD = ['מזהה', 'שם', 'תואר', 'יום', 'חודש', 'שנה', 'תאריך לועזי', 'אחרי השקיעה', 'יארצייט קבוע', 'הערה', 'פעיל'];
const NESH_KEYS = ['id', 'n', 't', 'd', 'm', 'y', 'g', 'as', 'fix', 'note', 'on'];
const NESH_SET = [   // מפתח, ברירת מחדל, הסבר
  ['theme', 'wood', 'עיצוב: wood = מסורתי (עץ ופליז), dark = כהה וזהב'],
  ['title', 'לוח נשמה', 'כותרת'],
  ['sub', '', 'שורה מתחת לכותרת (ריק = שם בית הכנסת)'],
  ['footer', 'הנצחה בלוח – לפרטים אצל הגבאי', 'שורה בתחתית (ריק = בלי)'],
  ['perPage', '16', 'שמות בכל עמוד (12 / 16 / 20 / 24)'],
  ['rotate', '12', 'שניות לכל עמוד'],
  ['adar', '', 'פטירה באדר של שנה פשוטה – בשנה מעוברת: 1 = אדר א, 2 = אדר ב (ריק = לפי הנוסח)'],
  ['order', 'date', 'סדר השמות: date = לפי תאריך הפטירה בשנה, abc = לפי א-ב'],
  ['week', 'כן', 'עמודת "יארצייטים השבוע" (כן / לא)']
];
const neshClean_ = (v, n) => { v = String(v == null ? '' : v).replace(/[\r\n\t]+/g, ' ').trim().slice(0, n || 80); return /^[=+\-@]/.test(v) ? "'" + v : v; };
function neshFolder_() { const it = DriveApp.getFoldersByName(NESH_FOLDER); return it.hasNext() ? it.next() : DriveApp.createFolder(NESH_FOLDER); }
const neshLinks_ = (id, key) => ({ display: DISPLAY_URL + 'neshama/?shul=' + id, app: DISPLAY_URL + 'neshama/settings.html?shul=' + id + '&key=' + key });
// זיהוי הקובץ של בית כנסת בתיקייה (כשהקישור בגיליון נמחק): קודם לפי התיאור "shul:<מזהה>", אחר כך לפי השם "לוח נשמה – <שם>"
const NESH_TAG = 'shul:';
function neshIndex_() {
  const byId = {}, byName = {}, it = neshFolder_().getFiles();
  while (it.hasNext()) {
    const f = it.next(); if (f.isTrashed()) continue;
    const m = String(f.getDescription() || '').match(/shul:([a-z0-9-]+)/);
    if (m) byId[m[1]] = f;
    (byName[f.getName()] = byName[f.getName()] || []).push(f);
  }
  return { byId, byName };
}
function neshFind_(idx, id, name) {
  let f = idx.byId[id];
  if (!f) {
    const a = (idx.byName['לוח נשמה – ' + name] || []).filter(x => !/shul:/.test(String(x.getDescription() || '')));
    if (a.length > 1) return { many: true };
    f = a[0];
    if (f) { try { f.setDescription(NESH_TAG + id); } catch (e) {} idx.byId[id] = f; }   // מסמנים – כדי שבפעם הבאה יזוהה גם אם השם השתנה
  }
  return f ? { url: f.getUrl() } : {};
}
function neshFileId_(row) { const m = String(row[C.neshFile] || '').match(/[-\w]{25,}/); return m ? m[0] : ''; }
function neshCreate_(name, email, id) {
  const ss = SpreadsheetApp.create('לוח נשמה – ' + name);
  const sh = ss.getSheets()[0].setName(NESH_TAB);
  sh.setRightToLeft(true);
  sh.getRange(1, 1, 1, NESH_HEAD.length).setValues([NESH_HEAD]).setFontWeight('bold');
  sh.setFrozenRows(1);
  sh.getRange(2, 1, 999, NESH_HEAD.length).setNumberFormat('@');   // הכול טקסט – שהגיליון לא יהפוך תאריכים ומספרים
  sh.hideColumns(1);   // המזהה – לשימוש האפליקציה
  const st = ss.insertSheet(NESH_SET_TAB);
  st.setRightToLeft(true);
  st.getRange(1, 1, NESH_SET.length + 1, 3).setNumberFormat('@').setValues([['מפתח', 'ערך', 'הסבר']].concat(NESH_SET));
  st.getRange(1, 1, 1, 3).setFontWeight('bold');
  const file = DriveApp.getFileById(ss.getId());
  file.moveTo(neshFolder_());
  if (id) file.setDescription(NESH_TAG + id);
  if (email) { try { file.addEditor(email); } catch (e) {} }
  return ss.getUrl();
}
// תפריט: הפעלת לוח נשמה לבית כנסת קיים – יוצר את הקובץ (אם אין) וקובע כמה מסכים
function neshEnable() {
  const ui = SpreadsheetApp.getUi();
  const r1 = ui.prompt('מזהה בית הכנסת (מעמודה "מזהה")', ui.ButtonSet.OK_CANCEL);
  if (r1.getSelectedButton() !== ui.Button.OK) return;
  const id = r1.getResponseText().trim().toLowerCase(), f = findRow_(id);
  if (!f) { ui.alert('לא נמצא בית כנסת עם המזהה הזה.'); return; }
  const r2 = ui.prompt('כמה מסכי לוח נשמה מאושרים? (מספר, 0 = כיבוי)', ui.ButtonSet.OK_CANCEL);
  if (r2.getSelectedButton() !== ui.Button.OK) return;
  const n = Math.max(0, parseInt(r2.getResponseText(), 10) || 0);
  let url = String(f.row[C.neshFile] || '');
  if (!neshFileId_(f.row)) {   // אין קישור – אולי נמחק בטעות: קודם מחפשים את הקובץ הקיים
    const r = neshFind_(neshIndex_(), id, String(f.row[C.name] || id));
    if (r.many) { ui.alert('בתיקייה "' + NESH_FOLDER + '" יש יותר מקובץ אחד בשם של בית הכנסת הזה.\nיש להדביק את הקישור הנכון בעמודה "קובץ לוח נשמה" ולהריץ שוב.'); return; }
    if (r.url) url = r.url;
    else if (n > 0) url = neshCreate_(String(f.row[C.name] || id), String(f.row[C.email] || '').trim(), id);
    if (url) f.sh.getRange(f.r, C.neshFile + 1).setValue(url);
  }
  f.sh.getRange(f.r, C.nesh + 1).setValue(n);
  CacheService.getScriptCache().remove('nesh_' + id);
  let key = String(f.row[C.key] || '');
  if (!key) { key = newKey_(); f.sh.getRange(f.r, C.key + 1).setValue(key); }
  if (!n) { ui.alert('לוח הנשמה כובה. הקובץ נשמר בדרייב.'); return; }
  const nl = neshLinks_(id, key);
  f.sh.getRange(f.r, C.neshDisplay + 1).setValue(nl.display);
  f.sh.getRange(f.r, C.neshApp + 1).setValue(nl.app);
  const links = 'קישור למסך:\n' + nl.display + '\n\nאפליקציה לגבאי:\n' + nl.app + '\n\nקובץ השמות:\n' + url;
  ui.alert('לוח הנשמה הופעל (' + n + ' מסכים). הקישורים נשמרו בגיליון.\n\n' + links);
  const email = String(f.row[C.email] || '').trim();
  if (email && ui.alert('לשלוח לגבאי את הקישורים במייל?\n' + email, ui.ButtonSet.YES_NO) === ui.Button.YES) {
    try { neshMail_(email, String(f.row[C.name] || id), nl, url); ui.alert('המייל נשלח ל-' + email); }
    catch (e) { ui.alert('המייל לא נשלח: ' + (e && e.message || e)); }
  }
}

function neshSettings_(ss) {
  const o = {}; NESH_SET.forEach(x => { o[x[0]] = x[1]; });
  const st = ss.getSheetByName(NESH_SET_TAB);
  if (st) st.getDataRange().getValues().slice(1).forEach(r => { const k = String(r[0]).trim(); if (k in o) o[k] = String(r[1]).trim(); });
  return o;
}
const neshTxt_ = v => v instanceof Date ? Utilities.formatDate(v, 'Asia/Jerusalem', 'yyyy-MM-dd') : String(v == null ? '' : v).trim();
function neshRows_(ss) {
  const sh = ss.getSheetByName(NESH_TAB);
  if (!sh || sh.getLastRow() < 2) return [];
  return sh.getRange(2, 1, sh.getLastRow() - 1, NESH_KEYS.length).getValues().map(r => {
    const o = {}; NESH_KEYS.forEach((k, i) => { o[k] = neshTxt_(r[i]); }); return o;
  }).filter(o => o.n);
}
// מיקום לחישוב השקיעה – מההגדרות של לוח הזמנים (ברירת מחדל: ירושלים)
function neshPlace_(row) {
  const s = parseJson_(row[C.settings]) || {};
  const lat = parseFloat(s.lat), lon = parseFloat(s.lon);
  return { lat: isNaN(lat) ? 31.778 : lat, lon: isNaN(lon) ? 35.235 : lon, tz: String(s.tz || 'Asia/Jerusalem'), nusach: String(row[C.nusach] || s.nusach || '') };
}
// המסך: ...exec?shul=ID&what=neshama&dev=&code=  → JSON
function neshDisplay_(id, p, cache) {
  const send = t => ContentService.createTextOutput(t).setMimeType(ContentService.MimeType.JSON);
  const f = findRow_(id);
  if (!f) return send(JSON.stringify({ ok: false, err: 'ERR:NOT_FOUND' }));
  if (!(parseInt(f.row[C.nesh], 10) > 0) || !neshFileId_(f.row)) return send(JSON.stringify({ ok: false, err: 'ERR:NESH_OFF' }));
  const dev = String(p.dev || '').replace(/[^a-z0-9]/gi, '').slice(0, 32);
  const err = checkDevice_(id, dev, String(p.code || '').replace(/\D/g, '').slice(0, 6), cache, 'n');
  if (err) return send(JSON.stringify({ ok: false, err }));
  const hit = cache.get('nesh_' + id);
  if (hit !== null) return send(hit);
  const ss = SpreadsheetApp.openById(neshFileId_(f.row));
  const t = JSON.stringify({ ok: true, name: String(f.row[C.name] || ''), place: neshPlace_(f.row), set: neshSettings_(ss),
    list: neshRows_(ss).filter(o => o.on !== 'לא').map(o => { delete o.id; delete o.on; return o; }), server: SERVER_BUILD });
  if (t.length < 95000) cache.put('nesh_' + id, t, 300);
  return send(t);
}
function neshAuth_(id, key) {
  const f = id ? findRow_(id) : null;
  if (!f || !key || String(f.row[C.key]) !== String(key)) throw new Error('הקישור אינו תקין. יש לפנות למנהל המערכת.');
  if (!neshFileId_(f.row)) throw new Error('לוח הנשמה עוד לא הופעל לבית הכנסת הזה. יש לפנות למנהל המערכת.');
  return f;
}
// האפליקציה: טעינה
function neshLoad_(id, key) {
  try {
    const f = neshAuth_(id, key), ss = SpreadsheetApp.openById(neshFileId_(f.row));
    return { ok: true, name: String(f.row[C.name] || ''), place: neshPlace_(f.row), set: neshSettings_(ss), list: neshRows_(ss),
      file: ss.getUrl(), screens: parseInt(f.row[C.nesh], 10) || 0, display: DISPLAY_URL + 'neshama/?shul=' + id };
  } catch (e) { return { ok: false, error: String(e && e.message || e) }; }
}
// האפליקציה: nput (הוספה / עדכון שורה לפי מזהה), ndel (מחיקה), nset (הגדרות)
function neshPost_(id, key, b) {
  const f = neshAuth_(id, key);
  const lock = LockService.getScriptLock(); lock.waitLock(15000);
  try {
    const ss = SpreadsheetApp.openById(neshFileId_(f.row));
    let out = { ok: true };
    if (b.action === 'nset') {
      const st = ss.getSheetByName(NESH_SET_TAB) || ss.insertSheet(NESH_SET_TAB);
      const cur = neshSettings_(ss), inp = b.set || {};
      st.clear();
      st.getRange(1, 1, NESH_SET.length + 1, 3).setNumberFormat('@').setValues([['מפתח', 'ערך', 'הסבר']].concat(NESH_SET.map(x => [x[0], neshClean_(x[0] in inp ? inp[x[0]] : cur[x[0]], 120), x[2]])));
      st.getRange(1, 1, 1, 3).setFontWeight('bold');
    } else {
      const sh = ss.getSheetByName(NESH_TAB);
      const last = sh.getLastRow(), ids = last > 1 ? sh.getRange(2, 1, last - 1, 1).getValues().map(r => String(r[0])) : [];
      const it = b.item || {}, at = it.id ? ids.indexOf(String(it.id)) : -1;
      if (b.action === 'ndel') {
        if (at < 0) throw new Error('השורה לא נמצאה (אולי נמחקה כבר)');
        sh.deleteRow(at + 2);
      } else {
        if (!neshClean_(it.n)) throw new Error('חסר שם');
        const rid = at >= 0 ? String(it.id) : Utilities.getUuid().replace(/-/g, '').slice(0, 10);
        const vals = NESH_KEYS.map(k => k === 'id' ? rid : neshClean_(it[k], k === 'note' ? 120 : 80));
        const r = at >= 0 ? at + 2 : last + 1;
        sh.getRange(r, 1, 1, vals.length).setNumberFormat('@').setValues([vals]);
        out.id = rid;
      }
    }
    CacheService.getScriptCache().remove('nesh_' + id);
    return out;
  } finally { lock.releaseLock(); }
}
