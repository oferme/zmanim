התקנת לוח הזמנים במחשב של בית הכנסת

מדריך מלא, מהמחשב הריק ועד מסך שעולה לבד כל בוקר. מתאים ל־Windows 10 ו־11.

  • א. מה צריך
  • ב. הורדת הקבצים
  • ג. התקנה אוטומטית
  • ד. אישור המסך
  • ה. הגדרות Windows
  • ו. קיצור דרך ואייקון ידנית
  • ז. זום ו־OBS (לא חובה)
  • ח. שימוש יומיומי
  • ט. תקלות נפוצות
  • י. הקבצים המלאים

אמה צריך

  • מחשב Windows 10 או 11 (גם מיני־מחשב קטן מאחורי המסך מתאים), מחובר למסך או לטלוויזיה ב־HDMI.
  • חיבור לאינטרנט (כבל רשת או Wi‑Fi).
  • דפדפן Google Chrome. אם אין – מורידים מ־google.com/chrome.
  • המזהה של בית הכנסת מגיליון הניהול, עמודה "מזהה" – למשל rs-bircat-mordechai.
  • בגיליון, בעמודה "מספר מסכים", צריך להיות מקום פנוי למסך הזה.

גהתקנה אוטומטית

  1. מפעילים את ההתקנה

    בתיקייה שחולצה לוחצים פעמיים על install.bat.
    אם מופיע חלון כחול "Windows הגן על המחשב שלך" – לוחצים מידע נוסף ← הפעל בכל זאת. זה קורה עם כל קובץ שהורד מהאינטרנט.

  2. מקלידים את מזהה בית הכנסת

    נפתח חלון שחור שמבקש ID. מקלידים את המזהה מהגיליון באנגלית, למשל rs-bircat-mordechai, ולוחצים Enter. למסך שני של אותו בית כנסת (למשל מסך תמונה במסדרון) מוסיפים רווח ו־2: rs-bircat-mordechai 2.

  3. ההתקנה מסתיימת לבד

    ההתקנה:
    • מעתיקה את הקבצים לתיקייה קבועה במחשב: %LocalAppData%\ZmanimDisplay
    • יוצרת קיצור דרך "לוח זמנים" עם האייקון בשולחן העבודה.
    • מוסיפה את אותו קיצור דרך להפעלה האוטומטית – כך שהמסך עולה לבד בכל הדלקה של המחשב.
    • פותחת את המסך מיד.
    בסוף לוחצים מקש כלשהו כדי לסגור את החלון השחור. את התיקייה zmanim-pc שבהורדות אפשר למחוק.

דאישור המסך

בפעם הראשונה שהמסך נפתח הוא נרשם לבד בגיליון "מסכים".
  • אם יש מקום במכסה של בית הכנסת – הוא מאושר מיד ולוח הזמנים עולה.
  • אם מופיע "מסך זה ממתין לאישור" עם קוד בן 4 ספרות – פותחים את הגיליון "מסכים", מוצאים את השורה עם הקוד, ומשנים את הסטטוס ל"מאושר". תוך דקה–שתיים המסך עולה.

ההגדרות Windows – שהמסך יעבוד לבד

  1. שהמחשב לא ייכנס לשינה

    הגדרות ← מערכת ← הפעלה ושינה (ב־Windows 11: "צריכת חשמל"). בשתי האפשרויות – כיבוי המסך ומצב שינה – בוחרים אף פעם.

  2. כניסה אוטומטית בלי סיסמה

    כדי שאחרי הפסקת חשמל המחשב יגיע לבד עד לוח הזמנים:
    1. לוחצים Win+R, כותבים netplwiz ולוחצים Enter.
    2. מבטלים את הסימון "על המשתמשים להזין שם משתמש וסיסמה" ← אישור, ומקלידים את הסיסמה פעמיים.
    אם האפשרות לא מופיעה ב־Windows 11: הגדרות ← חשבונות ← אפשרויות כניסה ← מכבים את "לאפשר כניסה עם Windows Hello בלבד", וחוזרים ל־netplwiz.

  3. עדכוני Windows לא בזמן תפילה

    הגדרות ← Windows Update ← אפשרויות מתקדמות ← שעות פעילות – מגדירים למשל 05:00 עד 23:00, כדי שהמחשב לא יופעל מחדש באמצע היום.

  4. דלוק אחרי הפסקת חשמל (לא חובה)

    רוב המחשבים לא נדלקים לבד כשהחשמל חוזר. בהגדרות ה־BIOS של המחשב יש בדרך כלל אפשרות בשם Restore on AC Power Loss או After Power Failure – מעבירים ל־Power On. הדרך להיכנס ל־BIOS שונה בין יצרנים (בדרך כלל Del או F2 בהדלקה). אם לא בטוחים – מדלגים.

  5. בודקים

    מפעילים מחדש את המחשב. בלי לגעת בכלום, לוח הזמנים אמור לעלות לבד במסך מלא תוך דקה.

וקיצור דרך ואייקון – ידנית

ההתקנה האוטומטית עושה את כל זה. החלק הזה למקרה שרוצים לעשות ידנית, או לתקן קיצור דרך שנמחק.

  1. תיקייה קבועה

    יוצרים תיקייה, למשל C:\Zmanim, ומעתיקים אליה את zmanim-online.bat, zoom-helper.ps1 ו־zmanim.ico. לא מזיזים אותם משם אחר כך.

  2. קובץ המזהה

    באותה תיקייה: קליק ימני ← חדש ← מסמך טקסט, קוראים לו shul.txt, פותחים אותו וכותבים בשורה הראשונה רק את המזהה (למשל rs-bircat-mordechai). שומרים.
    אם אין קובץ כזה, בפעם הראשונה ש־zmanim-online.bat רץ הוא שואל את המזהה ושומר אותו לבד.

  3. קיצור דרך בשולחן העבודה

    קליק ימני על zmanim-online.bat ← הצג אפשרויות נוספות (ב־Windows 11) ← שלח אל ← שולחן העבודה (צור קיצור דרך). בשולחן העבודה: קליק ימני על הקיצור ← שנה שם ← "לוח זמנים".

  4. האייקון

    קליק ימני על הקיצור ← מאפיינים ← לשונית קיצור דרך ← שנה סמל… ← עיון… ← בוחרים את zmanim.ico מהתיקייה ← אישור ← אישור.
    באותו חלון, בשדה הפעל, כדאי לבחור ממוזער – כך החלון השחור הקטן לא קופץ.

  5. הפעלה אוטומטית

    לוחצים Win+R, כותבים shell:startup ולוחצים Enter. נפתחת תיקיית ההפעלה האוטומטית. מעתיקים אליה את קיצור הדרך מהשולחן (קליק ימני ← העתק, ושם קליק ימני ← הדבק).
אם היו במחשב קיצורי דרך ישנים של לוח הזמנים (למשל לקובץ zmanim.html), מוחקים אותם משולחן העבודה ומ־shell:startup, כדי ששני מסכים לא ייפתחו יחד.

זשיעורי זום ו־OBS (לא חובה)

רק לבתי כנסת שמשתתפים בשיעור קבוע בזום. תוכנת העזר zoom-helper.ps1 כבר הותקנה ורצה ברקע; היא פועלת רק אם הגבאי הגדיר שיעור באפליקציה (לשונית "שליטה" ← "שיעור / שידור חי").
  1. מתקינים Zoom מ־zoom.us/download.
  2. בהגדרות Zoom: Audio – "Automatically join audio by computer" ו־"Mute my mic when joining". Video – "Enter full screen when joining".
  3. עם OBS ולוגו: מתקינים OBS, מכינים סצנה עם הלוגו וסוגרים. ב־Zoom, ב־Video, בוחרים מצלמה OBS Virtual Camera ולא מסמנים "Turn off my video when joining". תוכנת העזר פותחת את OBS שתי דקות לפני השיעור.
  4. ניסיון: באפליקציה מוסיפים שיעור להיום בעוד 5 דקות, למשך 10 דקות, ובודקים שהזום עולה ושהלוח חוזר בסוף.

אם משהו לא עובד, יש יומן בקובץ %LocalAppData%\ZmanimKiosk-zoom.log.

}
Write-Host ''
Write-Host 'Synagogue ID - from the management sheet, column "mazhe" (for example: ohel-moshe)'

while ($id -notmatch '^[a-z0-9-]+$') { $id = (Read-Host 'ID').Trim().ToLower() }

$name  = 'לוח זמנים.lnk'
foreach ($dir in @([Environment]::GetFolderPath('Desktop'), [Environment]::GetFolderPath('Startup'))) {
  $l = $shell.CreateShortcut((Join-Path $dir $name))
  $l.TargetPath = Join-Path $dest 'zmanim-online.bat'

  $l.IconLocation = (Join-Path $dest 'zmanim.ico') + ',0'

Start-Process (Join-Path $dest 'zmanim-online.bat') -WorkingDirectory $dest -WindowStyle Minimized
zoom-helper.ps1 – שיעורי זום ו־OBS 
# Zmanim display - Zoom helper.
# Runs hidden in the background (started by zmanim-online.bat).
# At the times the gabbai set in the settings app it closes the zmanim screen and joins the Zoom shiur
# (or opens the web site of the broadcast), and when the shiur time is over it returns to the zmanim screen.
# YouTube broadcasts are shown by the zmanim screen itself, so this helper ignores them.
param([string]$Page, [string]$Chrome, [string]$Api)

$ErrorActionPreference = 'SilentlyContinue'
# Windows PowerShell 5.1 does not always use TLS 1.2 by default - Google and YouTube require it
try { [Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12 } catch {}
$mutex = New-Object System.Threading.Mutex($false, 'Local\ZmanimZoomHelper')
if (-not $mutex.WaitOne(0)) { exit }          # already running

$shul = ''
if ($Page -match 'shul=([A-Za-z0-9-]+)') { $shul = $matches[1].ToLower() }
if (-not $shul -or -not $Api) { exit }
$kioskDir = Join-Path $env:LOCALAPPDATA 'ZmanimKiosk'
$logFile  = Join-Path $env:LOCALAPPDATA 'ZmanimKiosk-zoom.log'
function Log($t) { try { Add-Content -Path $logFile -Value ((Get-Date).ToString('yyyy-MM-dd HH:mm:ss') + '  ' + $t) -Encoding UTF8 } catch {} }

$sessions = @()
$lastFetch = [datetime]::MinValue
$current = $null      # key of the shiur we are in now
$currentType = ''
$done = @{}           # shiurim already joined (key -> $true)

function Fetch {
  try {
    $u = $Api + '?shul=' + $shul + '&what=zoom&t=' + [DateTime]::Now.Ticks
    $r = Invoke-WebRequest -UseBasicParsing -TimeoutSec 40 -Uri $u
    $txt = [Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray())
    if ($txt -match '^ERR') { return }
    $list = @()
    foreach ($l in ($txt -split "`n")) {
      $p = $l.Trim() -split '\|'
      if ($p.Count -ge 6 -and $p[0] -eq 'zoom') {
        $type = if ($p.Count -ge 7 -and $p[6]) { $p[6].Trim() } else { 'zoom' }
        $obs = -not ($p.Count -ge 8 -and $p[7].Trim() -eq '0')
        if ($type -ne 'youtube') {
          $list += [pscustomobject]@{ Day = [int]$p[1]; Start = $p[2]; End = $p[3]; Link = $p[4]; Name = $p[5]; Type = $type; Obs = $obs }
        }
      }
    }
    if ($list.Count -ne $script:sessions.Count) { Log ('schedule: ' + $list.Count + ' shiurim') }
    $script:sessions = $list
    $script:lastFetch = Get-Date
  } catch { Log ('fetch failed: ' + $_) }
}

function Minutes($hm) { $a = $hm -split ':'; return [int]$a[0] * 60 + [int]$a[1] }

# Is the shiur on now? Returns the key (date of the start + time), or $null
function ActiveKey($s, $now) {
  $st = Minutes $s.Start
  $en = if ($s.End) { Minutes $s.End } else { ($st + 90) % 1440 }
  $cur = $now.Hour * 60 + $now.Minute
  $dow = [int]$now.DayOfWeek
  if ($en -gt $st) {
    if ($dow -eq $s.Day -and $cur -ge $st -and $cur -lt $en) { return $now.ToString('yyyy-MM-dd') + ' ' + $s.Start }
  } else {   # crosses midnight (for example motzei Shabbat 23:00-00:30)
    if ($dow -eq $s.Day -and $cur -ge $st) { return $now.ToString('yyyy-MM-dd') + ' ' + $s.Start }
    if ((($dow + 6) % 7) -eq $s.Day -and $cur -lt $en) { return $now.AddDays(-1).ToString('yyyy-MM-dd') + ' ' + $s.Start }
  }
  return $null
}

function KioskProcs { Get-CimInstance Win32_Process -Filter "Name='chrome.exe'" | Where-Object { $_.CommandLine -like '*ZmanimKiosk*' } }
function Stop-Kiosk { KioskProcs | ForEach-Object { Stop-Process -Id $_.ProcessId -Force } }
function Start-Kiosk {
  if (KioskProcs) { return }
  Start-Process -FilePath $Chrome -ArgumentList @('--kiosk', ('--user-data-dir="' + $kioskDir + '"'), '--no-first-run',
    '--disable-session-crashed-bubble', '--hide-crash-restore-bubble', '--noerrdialogs', '--disable-translate', '--autoplay-policy=no-user-gesture-required', $Page)
}

function Start-OBS([int]$wait = 0) {   # optional: OBS virtual camera with the synagogue logo
  if (Get-Process obs64) { return }
  foreach ($p in @("$env:ProgramFiles\obs-studio\bin\64bit\obs64.exe", "${env:ProgramFiles(x86)}\obs-studio\bin\64bit\obs64.exe")) {
    if (Test-Path $p) {
      Start-Process -FilePath $p -WorkingDirectory (Split-Path $p) -ArgumentList @('--startvirtualcam', '--minimize-to-tray', '--disable-shutdown-check')
      Log 'OBS started'
      if ($wait -gt 0) { Start-Sleep -Seconds $wait }
      return
    }
  }
}

$liveDir = Join-Path $env:LOCALAPPDATA 'ZmanimLive'

    '--disable-session-crashed-bubble', '--hide-crash-restore-bubble', '--noerrdialogs', '--autoplay-policy=no-user-gesture-required', $s.Link)

}
function Close-Web {
  Get-CimInstance Win32_Process -Filter "Name='chrome.exe'" | Where-Object { $_.CommandLine -like '*ZmanimLive*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
}

function Resolve-ZoomLink($link) {   # short / redirect links (e.g. https://zoom.mydomain.com) -> the real zoom.us/j/... link
  if ($link -match 'zoom\.(us|com)/(j|w)/\d+') { return $link }
  try {
    $r = Invoke-WebRequest -UseBasicParsing -Uri $link -MaximumRedirection 6 -TimeoutSec 20
    $final = ''
    try { $final = $r.BaseResponse.ResponseUri.AbsoluteUri } catch {}
    if (-not $final) { try { $final = $r.BaseResponse.RequestMessage.RequestUri.AbsoluteUri } catch {} }
    if ($final -match 'zoom\.(us|com)/(j|w)/\d+') { return $final }
    if ($r.Content -match '(https://[\w.-]*zoom\.(us|com)/(j|w)/\d+[^\s"''<>]*)') { return ($matches[1] -replace '&amp;', '&') }
  } catch { Log ('resolve failed: ' + $_) }
  return $link
}

function Join-Zoom($s) {
  $name = [uri]::EscapeDataString($s.Name)
  $s.Link = Resolve-ZoomLink $s.Link
  if ($s.Link -match '/(?:j|w)/(\d+)') {
    $conf = $matches[1]
    $pw = ''
    if ($s.Link -match '[?&]pwd=([^&#\s]+)') { $pw = '&pwd=' + $matches[1] }
    $url = 'zoommtg://zoom.us/join?action=join&confno=' + $conf + $pw + '&uname=' + $name
  } else {
    $url = $s.Link   # other link types - opened as is
  }
  Start-Process $url
  Log ('join ' + $s.Start + ' ' + $s.Link)
}

function Leave-Zoom {
  Get-Process Zoom | Stop-Process -Force
  Log 'leave'
}

function ZoomInstalled { return (Test-Path 'Registry::HKEY_CLASSES_ROOT\zoommtg') }
if (-not (ZoomInstalled)) { Log 'Zoom is not installed yet (zoommtg link not registered)' }
Log ('helper started for ' + $shul)

while ($true) {
  if (((Get-Date) - $lastFetch).TotalMinutes -ge 2) { Fetch }
  $now = Get-Date
  $active = $null; $key = $null
  foreach ($s in $sessions) { $k = ActiveKey $s $now; if ($k) { $active = $s; $key = $k } }
  # OBS opens 2 minutes before a Zoom shiur, so the logo camera is ready when Zoom joins
  if (-not $active) {
    foreach ($s in $sessions) { if ($s.Type -eq 'zoom' -and $s.Obs -and (ActiveKey $s $now.AddMinutes(2))) { Start-OBS } }
  }

  if ($active -and -not $done.ContainsKey($key) -and $active.Type -eq 'zoom' -and -not (ZoomInstalled)) {
    if (-not $done.ContainsKey('nozoom ' + $key)) { $done['nozoom ' + $key] = $true; Log 'shiur time, but Zoom is not installed - install Zoom from zoom.us/download' }
  }
  elseif ($active -and -not $done.ContainsKey($key)) {
    $done[$key] = $true
    $script:current = $key
    $script:currentType = $active.Type
    Stop-Kiosk
    if ($active.Type -eq 'web') { Open-Web $active }
    else {
      if ($active.Obs) { Start-OBS 15 }   # normally already open from 2 minutes before
      Join-Zoom $active
    }
  }
  elseif ($current -and $current -ne $key) {   # shiur time is over (or the shiur was deleted)
    $script:current = $null
    if ($currentType -eq 'web') { Close-Web } else { Leave-Zoom }
    Start-Sleep -Seconds 3
    Start-Kiosk
  }
  Start-Sleep -Seconds 20
}
